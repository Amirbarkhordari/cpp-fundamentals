# مبانی برنامه‌نویسی C++ (C++ Fundamentals)

## معرفی پروژه

این مخزن شامل سه تمرین برنامه‌نویسی به زبان C++ است. این تمرین‌ها را برای تمرین مفاهیم اولیه برنامه‌نویسی و قوی‌تر شدن در حل مسئله نوشته‌ام.

## پروژه‌های موجود

### 1. EvenNumberSum

در این برنامه یک عدد از ورودی می‌گیرم و عددهای زوج از ۱ تا همان عدد را پیدا می‌کنم. هر عدد زوج را چاپ می‌کنم و بین آن‌ها علامت `+` می‌گذارم. در پایان، مجموع همین عددها را نمایش می‌دهم.

اگر عدد ۱۰ وارد شود، خروجی برنامه این است:

```
Enter a number: 10
Even numbers are:
2 + 4 + 6 + 8 + 10
Sum = 30
```

### 2. PerfectNumbers

این برنامه عددهای کامل بین ۱ تا ۱۰۰۰ را پیدا می‌کند. عدد کامل عددی است که مجموع مقسوم‌علیه‌های مثبت آن، به‌جز خودش، با خود عدد برابر باشد.

برای هر عدد، مقسوم‌علیه‌های کوچک‌تر از خودش را با عملگر `%` بررسی می‌کنم و آن‌ها را با هم جمع می‌کنم. اگر حاصل جمع با خود عدد برابر باشد، آن عدد را چاپ می‌کنم.

خروجی واقعی برنامه:

```
Perfect numbers from 1 to 1000:
6
28
496
```

### 3. ReverseNumber

در این برنامه یک عدد از ورودی می‌گیرم و رقم‌های آن را از آخر به اول چاپ می‌کنم. آخرین رقم را با `% 10` جدا می‌کنم و نمایش می‌دهم. بعد عدد را بر ۱۰ تقسیم می‌کنم تا آن رقم حذف شود. این کار را تا وقتی که عدد بزرگ‌تر از صفر است ادامه می‌دهم.

اگر عدد ۱۲۳۴۵ وارد شود، خروجی برنامه این است:

```
Enter a number: 12345
54321
```

## مفاهیم تمرین‌شده

در این سه برنامه از این موارد استفاده کرده‌ام:

- متغیرها و نوع داده `int`
- دستور شرطی `if`
- حلقه `for` و حلقه `while`
- حلقه تو در تو برای پیدا کردن عددهای کامل
- عملگرهای `+`، `/` و `%`
- دریافت ورودی با `cin` و نمایش خروجی با `cout`

## تکنولوژی‌های استفاده‌شده

- C++
- Standard C++ Library

## نحوه اجرا

هر برنامه فقط یک فایل `cpp` دارد. برای اجرا، وارد پوشه همان پروژه می‌شوم و فایل را با `g++` کامپایل می‌کنم.

### EvenNumberSum

```bash
cd EvenNumberSum
g++ EvenNumberSum.cpp -o EvenNumberSum.exe
EvenNumberSum.exe
```

### PerfectNumbers

```bash
cd PerfectNumbers
g++ PerfectNumbers.cpp -o PerfectNumbers.exe
PerfectNumbers.exe
```

### ReverseNumber

```bash
cd ReverseNumber
g++ ReverseNumber.cpp -o ReverseNumber.exe
ReverseNumber.exe
```
